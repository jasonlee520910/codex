# 시니어 테트리스

맥에서 바로 열어 즐길 수 있는 테트리스 게임입니다.

## 실행 방법

1. `index.html`을 더블클릭해서 브라우저로 여세요.
2. 추천 브라우저는 Safari 또는 Chrome입니다.

## 규칙

- 1단계는 10줄을 지우면 클리어됩니다.
- 2단계는 20줄, 3단계는 30줄처럼 단계별 목표가 10줄 단위로 늘어납니다.
- 총 10단계까지 진행되며, 10단계를 끝내면 최종 클리어입니다.

## 조작

- `← →` 이동
- `↑` 회전
- `↓` 한 칸 내리기
- `Space` 즉시 내리기
- `P` 일시정지
- `R` 재시작

## 특징

- 큰 글씨와 선명한 색감
- 단계별 속도 상승
- 다음 블록 미리보기
- 마우스 클릭 버튼 조작 지원
